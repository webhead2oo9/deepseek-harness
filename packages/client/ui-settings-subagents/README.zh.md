# @deepseek-ai/dsh-client-ui-settings-subagents

[English](README.md) | 中文

此浏览器 Cordis 插件注册 `subagents` 设置页面。它编辑 Host 的 `subagent-model-selection` 命名空间，其值包含 `allowDirectModelSelection` 和配置字典。每项配置包含描述、提供商、模型，以及可选的多行子代理系统指令和适配器自有推理强度 ID。编辑器会省略空白可选字段，并在卡片预览中显示已配置的指令与强度值。配置名称与已存储字段按输入原样保存；模型适配器数据仅用于建议，不会限制手动填写的路由或强度字符串。实际使用配置时，由确切子代理路由校验推理强度。

页面同时读取 `settings.describe` 与 `llm.models`。写入通过 `settings.mutate` 路径操作完成，并携带命名空间描述中的当前 revision。写入成功后采用响应返回的值与 revision。组合拥有的配置会标记为部署默认值：用户层可以覆盖其路由字段，但 UI 不提供只会让同一个基础配置重新出现的重命名或删除操作。设置提供方为只读时，页面仍显示当前值，但禁用所有编辑控件。该命名空间的设置文档更新、适配器拓扑更新与连接重置会刷新已经加载过的页面。

## 模型体验

### 间接影响父级委派 schema

#### 模型看到的内容

此页面修改兼容 [`subagent` 委派工具](../../../docs/tool-catalog.md#deepseek-aidsh-tool-subagent)所消费的 Host 设置。具名配置会把名称与说明加入可选 `profile` 字段；开启直接选择会加入可选 provider/model 字段，并为兼容后端加入可选的直接推理强度字段。所选配置的指令会成为额外的、仅对子代理生效的系统提示词 section，而推理强度会为确切路由配置子代理模型调用；UI 包自身不组装模型请求。

#### Token 影响

每个已配置项会将其名称与说明加入公开兼容委派工具的每个父级请求。根据后端是否支持推理强度，直接选择会增加两个或三个可选字符串字段。已配置的指令还会把自身文本加入每个使用该配置的子代理请求；推理强度可能改变子代理模型的推理 token 用量。子 agent 的 token 用量取决于解析后的 provider/model 路由，并保留在子会话中。

#### KV Cache 影响

配置设置与生成的工具 schema 不变时保持稳定。配置或直接选择开关变化会重新注册工具，并可能从变化的定义开始使父级复用失效；后续子 agent 路由使用该 provider/model 的独立缓存。

## 已知限制与延期工作

- 建议仅包含当前已连接适配器报告的模型与推理强度。对于离线、私有或未收录的适配器、模型与强度 ID，仍可手动填写字符串；兼容性错误只会在子代理使用确切路由时出现。
